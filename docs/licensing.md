# Licensing rule for agents

Treat other drone-show projects as **interoperability references**, not source to copy.

- Skybrush Studio and Skybrush Server are **GPL-3.0-or-later**.
- If Lumina uses a non-GPL license, do not vendor their code, plugins, or firmware.
- Implement CSV / documented interchange exporters independently.
- Do a license review before incorporating any GPL component.

VVIZ is a visualization interchange format. Exported VVIZ must be labeled **not flight-ready**.

MAVLink is a later runtime/transport layer. It is not the show-file format.
